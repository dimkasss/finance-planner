# Финансовый помощник

Fullstack-приложение для управления личными финансами. Позволяет отслеживать доходы и расходы, управлять категориями с лимитами и анализировать финансовое состояние с помощью графиков.

## Стек технологий

### Backend
- **Node.js** + **Express.js** — REST API сервер
- **Prisma ORM** — работа с базой данных
- **SQLite** — база данных (файловая, не требует установки)
- **JWT** — авторизация
- **Zod** — валидация данных
- **bcryptjs** — хеширование паролей

### Frontend
- **Next.js 14** (App Router) — React-фреймворк
- **TypeScript** — типизация
- **Material UI (MUI) v6** — UI-компоненты
- **Recharts** — графики и диаграммы

## Быстрый старт

### Требования
- Node.js 18+
- npm

### 1. Установка и запуск Backend

```bash
cd backend
npm install
npx prisma generate
npx prisma migrate dev --name init
npx ts-node prisma/seed.ts   # (опционально) создаёт демо-пользователя
npm run dev
```

Сервер запустится на `http://localhost:4000`

### 2. Установка и запуск Frontend

```bash
cd frontend
npm install
npm run dev
```

Приложение откроется на `http://localhost:3000`

## REST API эндпоинты

### Авторизация
| Метод | URL | Описание |
|-------|-----|----------|
| POST | `/api/auth/register` | Регистрация |
| POST | `/api/auth/login` | Вход |
| GET | `/api/auth/me` | Текущий пользователь |

### Операции (транзакции)
| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/api/transactions` | Список операций (с фильтрами и пагинацией) |
| GET | `/api/transactions/balance` | Текущий баланс |
| POST | `/api/transactions` | Создать операцию |
| PUT | `/api/transactions/:id` | Редактировать операцию |
| DELETE | `/api/transactions/:id` | Удалить операцию |

### Категории
| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/api/categories` | Список категорий (с текущими расходами) |
| POST | `/api/categories` | Создать категорию |
| PUT | `/api/categories/:id` | Редактировать категорию |
| PUT | `/api/categories/:id/limit` | Установить месячный лимит |
| DELETE | `/api/categories/:id` | Удалить категорию |

### Аналитика
| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/api/analytics/expenses-by-category` | Расходы по категориям (круговая диаграмма) |
| GET | `/api/analytics/income-expense-trend` | Динамика доходов/расходов (линейный график) |
| GET | `/api/analytics/limits-status` | Статус лимитов по категориям |

## Функционал

### Регистрация и авторизация
- Регистрация с email, именем и паролем
- Вход по email и паролю
- JWT-токен хранится в localStorage
- Автоматическое создание стандартных категорий при регистрации

### Главная панель (Dashboard)
- Текущий баланс (доходы минус расходы)
- Карточки с суммой доходов и расходов
- Прогресс-бары по лимитам категорий
- Предупреждения о превышении лимитов
- Последние 5 операций

### История операций
- Таблица всех операций в хронологическом порядке
- Фильтрация по типу (доход/расход), категории, дате
- Пагинация
- Создание, редактирование и удаление операций
- Формат операции: тип, сумма, категория, дата, комментарий

### Категории и лимиты
- Создание и редактирование категорий с иконками
- Установка месячных лимитов расходов
- Визуальное отображение прогресса по лимитам
- Предупреждения при превышении лимита
- Удаление категорий (с каскадным удалением операций)

### Аналитика
- **Круговая диаграмма** — структура расходов по категориям за день/неделю/месяц
- **Линейный график** — динамика доходов и расходов за 3/6/12 месяцев
- Интерактивные тултипы при наведении
